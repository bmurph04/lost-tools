#   src/  +  external/fast_foundationstereo  +  external/track_on

# Deliberately EXCLUDED: external/depth_pro, external/react, external/FROSS/EGTR,

#
# NOTE: mmcv is NOT required. Track-On needs one symbol from it
# (MultiScaleDeformableAttention); mmcv's last release is v2.2.0 (Apr 2024),
# which cannot compile sm_120 kernels for Blackwell. src/compat/mmcv/ provides a
# replacement, wired up in src/main.py: it uses the prebuilt fused CUDA kernel
# from the HF Hub when `kernels` is installed, and a pure-PyTorch grid_sample
# path otherwise. Neither route needs nvcc.

# --- STEP 1: torch. Install FIRST, from the cu130 index:
#       pip install torch torchvision --index-url https://download.pytorch.org/whl/cu130
#
#     Two constraints fix this choice:
#       * Blackwell (compute capability 12.0) needs sm_120 kernels -> torch >= 2.7
#         built with cu128 or newer. Older cu124 builds have no Blackwell kernels.
#       * rfdetr requires transformers>=5.1, which deactivates its torch
#         integration on torch < 2.5 (symptom: "cannot import name
#         'BackboneConfigMixin' from 'transformers'").
#     cu130 specifically, rather than cu128, so it matches a system CUDA 13.x
#     toolchain: DPVO compiles CUDA extensions, and torch hard-errors when nvcc's
#     MAJOR version differs from the one torch was built with (13.3 vs 13.0 is
#     only a warning; 13.3 vs 12.x is fatal).

torchvision
